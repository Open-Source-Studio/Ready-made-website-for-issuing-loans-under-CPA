## 📋 Краткий обзор проекта

Данный проект представляет собой готовое решение для создания сайта по выдаче займов с использованием модели Cost Per Action (CPA). Проект построен на основе WordPress и включает специальный установщик для автоматического развертывания.

### Основные компоненты:
- **WordPress Core Files** - стандартные файлы WordPress
- **Installer System** - система установки на базе Duplicator Plugin v1.5.0
- **Configuration Files** - файлы конфигурации и документация на русском языке
- **Backup Files** - резервная копия установщика
